# PharmaSys V13.5.0 — Assistants : dépenses et ventes à crédit

## Fonctionnalités
- Les assistants disposent d'une rubrique **Mes dépenses journalières**.
- Chaque dépense est enregistrée comme mouvement de caisse `SORTIE` avec `nature='DEPENSE'`.
- La dépense est liée à l'utilisateur par `assistant_id` et `assistant`.
- Les dépenses apparaissent dans le panneau Finance Admin et dans le rapport journalier existant.
- L'assistant peut vendre en **Espèces, Mobile Money, Carte, Crédit/Dette ou Mixte**.
- Une vente à crédit exige un client actif.
- Les crédits utilisent le mécanisme transactionnel existant `valider_vente`.
- Le tableau Admin des crédits est calculé sur l'ensemble de l'historique, indépendamment de la période du dashboard.
- Les ventes à crédit saisies hors-ligne conservent leurs paiements et sont synchronisées avec la même transaction à la reconnexion.

## Migration Supabase à appliquer
Exécuter :
`supabase/migrations/20261004000100_assistant_expenses_credit_balances.sql`

Cette migration ajoute :
- `mouvements_caisse.assistant_id`
- RPC `enregistrer_depense_assistant`
- RPC `get_credit_balances`
- support hors-ligne `DEPENSE_ASSISTANT`
- restrictions d'insertion directe sur caisse/paiements
- contrôle serveur de l'identité du vendeur pour les assistants

## Déploiement
1. Appliquer la migration Supabase.
2. Déployer la nouvelle version du projet.
3. Le Service Worker est passé à `pharmasys-shell-v13-perf2` pour forcer le rafraîchissement du shell applicatif.
