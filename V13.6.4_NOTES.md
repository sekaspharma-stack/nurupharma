# PharmaSys V13.6.4 — Hotfix SQL crédit

## Correctif
- Correction de la migration `20261004000300_credit_traceability.sql`.
- Le bloc de compatibilité utilisait `p` comme alias SQL alors que `p` est aussi le record PL/pgSQL. PostgreSQL interprétait `p.id` comme un champ du record non encore assigné et produisait `SQLSTATE 55000`.
- L'alias de la table `paiements` est maintenant `pay`, ce qui supprime l'ambiguïté.
- Le schéma public est synchronisé avec la migration corrigée.

## À exécuter
Si la migration V13.6.3 a échoué dans le SQL Editor, exécuter à nouveau la migration corrigée fournie dans le ZIP.
